🎁 Conhecendo os Containers do Bootstrap

Redimensione a janela do navegador para observar o comportamento de cada container

📦 container

Sou o container mais utilizado

Imagine uma mochila. Ela cresce até um limite e depois para. Mesmo em uma tela enorme ela permance organizada.

Explicando as Classes
Container = cria o container responsivo.
bg-success-subtle = fundo verde claro.
border = adiciona borda.
border-5 = borda grossa.
rounded-4 = cantos arredondados.
shadow-lg = sombra grande.
p-4 = espaçamento interno.
mb-5 = espaço abaixo da caixa.

🚛 .container-fluid

Ocupa toda a tela!

Imagine uma tinta sendo derramada de uma ponta até a outraa

Ocupa sempre 100% da largura.
Ideal para banners, menus e rodapés

🏥 .container-sm

SM = Small

Breakpoint: 576px

Antes de 576px ocupa toda a largura.
Depois fica centralizado

.container-md

MD = Medium

Breakpoint: 768px

Espera a tela ficar média para limitar a largura.
Depois fica centralizada

.container-lg

LG = Large

Breakpoint: 992px

Muito usado em notebooks

.container-xl

XL = Extra Large

Breakpoint: 1200px

Ideal para monitores grandes

.container-xxl

XXL = Extra Extra Large

Breakpoint: 1400px

Ideal para monitores ultrawide e TVs
